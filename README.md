# Microinversor Solar Monitor

Monitor doméstico de generación solar para dispositivos compatibles con Tuya Cloud, desarrollado con Python, Streamlit y SQLite.

Funciones previstas: potencia, tensión, corriente, generación horaria, ahorro estimado, diagnóstico, alertas, meteorología y respaldos.

## Seguridad
Nunca publiques el archivo `.env`, la base de datos `data/`, respaldos, credenciales, identificadores de dispositivos ni claves locales. Configura las credenciales exclusivamente en tu equipo.

## Instalación
El paquete completo de código de la versión 1.8 está preparado para incorporarse al repositorio. Crea tu archivo `.env` a partir de `.env.example` y mantén el puerto 8501 restringido a tu LAN.
